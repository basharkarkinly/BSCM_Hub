# BAC504 — المحاسبة المالية في الشركات
### منصة دراسة تفاعلية — Support Channel 🔵

منصة ويب تفاعلية باللغة العربية لمراجعة مقرر **BAC504 (محاسبة شركات الأشخاص والأموال)** في الجامعة الافتراضية السورية (SVU)، مبنية فوق محاضرات د. سمر حبيب وبنك أسئلة الدورات الحقيقي لقناة Support Channel.

> 🔔 **تنويه:** هاي المنصة أداة **مراجعة** مكمّلة، وما بتغني إطلاقاً عن دراسة المقرر الأساسي ومحاضرات الدكتورة.

---

## 🧭 شو فيها؟

| الفصل | العنوان |
|---|---|
| 1 | مفهوم الشركات وأنواعها |
| 2 | إجراءات تكوين شركات التضامن والتوصية البسيطة |
| 3 | إعادة تنظيم شركات التضامن والتوصية البسيطة |
| 4 | الحسابات الجارية للشركاء وطرق توزيع الأرباح والخسائر |
| 5 | تصفية (انقضاء) شركات التضامن |
| 6 | التعريف بشركات الأموال وخصائصها |
| 7 | تعديل رأس المال وتوزيع الأرباح في الشركات المساهمة |

لكل فصل 3 صفحات:
- **الدرس (Lesson):** شرح مبسّط بالعامية السورية، مبني على شرائح المحاضرة الرسمية، مع جداول مقارنة وأمثلة ومسائل محلولة.
- **التدريب الحر (Practice):** بنك أسئلة الفصل، بلا قفل ولا ضغط وقت، تقدر تعيد المحاولة قد ما بدك.
- **امتحان الفصل (Exam):** يتطلب **90%** فما فوق لفتح الفصل التالي.

بالإضافة لـ **فحص نهائي شامل** (`pages/final-exam.html`) بياخد عيّنة عشوائية من **100 سؤال** من أصل بنك شامل فيه حوالي **220 سؤال** عبر الفصول السبعة (منها أسئلة حقيقية من بنك دورات BAC504_F22 و BSCM_BAC504_S23، والباقي مولّد بنفس نمط الأسئلة الحقيقية وبأرقام محقّقة حسابياً).

## 🧩 الأدوات التفاعلية

كل فصل فيه أدواته الخاصة المبنية على طبيعة محتواه:

- **مسائل موجّهة (Guided Problems):** تُحل خطوة بخطوة — حساب رقم، اختيار جواب، أو بناء قيد محاسبي كامل (اختيار الحساب + المبلغ لكل سطر مع فحص توازن مباشر)، مع تلميح وزر "وريني الحل" لكل خطوة.
- **لعبة التصنيف (Tap-to-sort):** بطاقات خصائص تُصنَّف حسب نوع الشركة، مع تفسير فوري لكل إجابة.
- **مقياس المسؤولية التفاعلي:** يقارن بصريًا مين من الشركاء معرَّض لأمواله الخاصة حسب نوع الشركة ومقدار الديون.
- **حاسبات تفاعلية:** علاوة الإصدار، مقارنة صافي الأصول بالحصة، مبدّل "قيم دفترية ↔ إعادة تقدير"، وغيرها.
- **بطاقات مصطلحات قابلة للقلب (Flashcards)** في آخر كل فصل.

## 🗂️ هيكلية المشروع

```
bac504/
├── index.html                    ← الصفحة الرئيسية (خريطة المقرر + التقدّم)
├── chapters/
│   ├── chapter-N-lesson.html     ← الدرس (N = 1…7)
│   ├── chapter-N-practice.html   ← التدريب الحر
│   └── chapter-N-exam.html       ← امتحان الفصل (قفل تسلسلي 90%)
├── pages/
│   └── final-exam.html           ← الفحص النهائي الشامل (100 سؤال عشوائي)
└── assets/
    ├── app.js                    ← محرّك الموقع: القائمة الجانبية، نظام الأسئلة، التقدّم (localStorage)، الفلاشكاردز
    ├── extras.js                 ← المكوّنات التفاعلية الإضافية (مسائل موجّهة، ألعاب، حاسبات)
    ├── style.css / extras.css    ← التصميم (نظام تصميم مشترك + تنسيقات المكوّنات الإضافية)
    ├── img/                      ← شعار القناة
    └── data/
        ├── course-manifest.js    ← بيانات الفصول (العناوين والروابط وآلية الفتح التسلسلي)
        ├── chN-questions.js      ← بنك أسئلة كل فصل (origin: "bank" حقيقي / "gen" مولّد)
        └── final-questions.js    ← دمج كل البنوك لبنك الفحص النهائي
```

## ⚙️ كيف تشتغل المنصة تقنياً

- **بدون أي خادم أو بناء (build)** — HTML/CSS/JS عادي، فيك تفتحها بفتح `index.html` مباشرة بالمتصفح، أو تنشرها كـ static site (GitHub Pages, Netlify, Vercel...).
- **التقدّم محفوظ محلياً** بالمتصفح (`localStorage`)، ما في أي قاعدة بيانات أو سيرفر خلفي. فتح الموقع من متصفح أو جهاز تاني بيبلّش التقدّم من الصفر.
- **القفل التسلسلي:** الفصل N+1 ما بينفتح إلا بعد اجتياز امتحان الفصل N بنسبة 90% فأكثر (قابلة للتعديل من `app.js`).
- **تصميم متجاوب بالكامل (Mobile-first):** القائمة الجانبية عبارة عن لوحة منزلقة (☰) تشتغل نفس الطريقة عالموبايل واللابتوب.
