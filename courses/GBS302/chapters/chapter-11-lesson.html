التنسيق والطباعة في Excel

تنسيق أوراق العمل ومحتوى الخلايا، التنسيق الشرطي، ضبط إعدادات ورقة العمل (الهوامش، الاتجاه، الحجم، الرأس والتذييل، خطوط الشبكة)، والطباعة.

🔑 كلمات مفتاحية

Wrap TextMerge & Center Conditional FormattingData Bars Color ScalesIcon Sets MarginsGridlinesPrint Titles

🎯 بعد هالفصل لازم تقدر:

  • تنسّق ورقة العمل: التفاف، محاذاة، اتجاه، دمج، حدود
  • تنسّق محتوى الخلايا وتحفظ اختصارات الخط
  • تطبّق التنسيق الشرطي وتفرّق بين أنواعه
  • تضبط الهوامش والاتجاه والحجم والرأس والتذييل وخطوط الشبكة
  • تطبع اللي بدك ياه بالضبط

1 تنسيق أوراق العمل

تنسيق أوراق العمل ممكن ما يكون ضروري، بس بيعطي جاذبية وبيسهّل القراءة وبيساعد الآخرين يفهمو المطلوب. ومنه (Home ← Alignment):

التنسيقشو بيعمل
التفاف النص Wrap Textبيظهر النص على أكتر من سطر بنفس الخلية (ونفس الأيقونة للإلغاء)
المحاذاةTop · Middle · Bottom · Left · Center · Right
الاتجاه Orientationخيارات جاهزة أو زاوية، متل Angle Counterclockwise (45°)
دمج الخلايا Merge & Centerخلايا متجاورة أفقياً أو عمودياً بخلية وحدة، غالباً لعناوين الأعمدة (ونفس الأيقونة للإلغاء)
الحدود Bordersالخلايا بتنطبع بلا حدود؛ ضيف Outside Borders أو غيرها
⚠️ فخ امتحان

لما تدمج خلايا مو فاضية، بيضل بس محتوى الخلية العلوية اليسارية. و«التفاف النص» من تنسيقات أوراق العمل (مو محتوى الخلية) حسب المقرر.

2 تنسيق محتوى الخلايا

من Home ← Font: حجم الخط (أو Increase / Decrease Font Size)، نوعه، لونه Font Color، ولون خلفية الخلية Fill Color.

النمطالاختصار
غامق BoldCtrl + B أو Ctrl + 2
مائل ItalicCtrl + I أو Ctrl + 3
تسطير UnderlineCtrl + U أو Ctrl + 4
تسطير مزدوجما إله اختصار

3 التنسيق الشرطي

بيطبّق تنسيقات تلقائياً حسب محتوى الخلية (موجب ← أخضر، سالب ← أحمر). ولما تتغيّر القيم بيتغيّر التنسيق لحاله. ممتاز لاكتشاف أخطاء الإدخال والقيم الشاذة. المكان: Home ← Style ← Conditional Formatting.

الخيارشو بيعمل
قواعد تمييز الخلايا Highlight Cells Rulesمعايير كتيرة: أكبر أو أصغر من قيمة، بين قيمتين، نص محدد، قيم مكررة، تواريخ (Equal To...)
القواعد العليا / الدنيا Top / Bottom Rulesحسب القيم والنسب العليا والدنيا (أعلى 10، أعلى 10%، فوق أو تحت المتوسط)
أشرطة البيانات Data Barsأشرطة ملونة طولها حسب نسبة القيمة لباقي القيم
مقاييس الألوان Color Scalesلوحة ألوان ثنائية أو ثلاثية بتتدرّج حسب القيم
مجموعات الأيقونات Icon Setsأيقونات لتمييز القيم ببعضها (سهم أحمر للدنيا، أصفر للوسطى، أخضر للعليا)
قاعدة جديدة New Ruleقاعدة خاصة بالمستخدم (متل Use a formula... =$B2="غير متوفر")
مسح القواعد Clear Rulesمن الخلايا المحددة أو من الورقة كلها
إدارة القواعد Manage RulesConditional Formatting Rules Manager: تحرير، حذف، وتعديل الأولوية

وفيك تطبّق أكتر من تنسيق على نفس النطاق (متل Data Bars + Icon Sets).

4 ضبط إعدادات ورقة العمل (Page Layout ← Page Setup)

📏 الهوامش Marginsالمنطقة الفارغة حول حدود الصفحة، والنص بين الهوامش. معرّفة مسبقاً: Normal · Wide · Narrow، أو Custom Margins.
🔄 الاتجاه OrientationPortrait طولي (الطول أكبر) · Landscape بالعرض (العرض أكبر).
📄 الحجم Sizeحجم صفحة الطباعة.
🔝 الرأس والتذييلمناطق ضمن الهوامش العلوية والسفلية — Insert ← Text ← Header & Footer — 3 أماكن: يسار، منتصف، يمين.

حقول الرأس والتذييل (من Design): Page Number · Number of Pages · Current Date · Current Time · File Path · File Name · Sheet Name · Picture. وبتحذف الحقل بتحديده و Delete. وفيك تدرج رسومات بيانية كمان.
