1 البريد الإلكتروني وأجزاء العنوان

البريد الإلكتروني E-mail خدمة إلكترونية لإرسال واستقبال الرسائل (نصوص، صور، ملفات صوتية...) عبر الإنترنت، لشخص محدد أو مجموعة. ولكل مستخدم عنوان بالشكل UserName@provider.com:

  1. 1

    اسم المستخدم Username

    بتختاره إنت، ولازم يكون فريد وغير محجوز ضمن نفس مزود الخدمة.

  2. 2

    الرمز @

    بين اسم المستخدم وباقي العنوان.

  3. 3

    اسم النطاق Domain Name

    Provider = اسم مزود الخدمة (Gmail، Yahoo) + الامتداد اللي بيعبّر عن نشاط المزود.

3 مسائل الحماية والأمان

📨 الرسائل المخادعة SPAMغالباً خبيثة (فيروسات أو احتيال) أو دعاية. لا ترد عليها: الرد بيثبت هويتك فبيغرقوك بأكتر.
🎣 الاحتيالبريد مزيف من مرسل بيتظاهر إنه جهة حقيقية، فيه رابط لموقع مزيف لسرقة بطاقة الائتمان والحسابات البنكية.
🦠 الفيروساتبرنامج خبيث بيأثر سلبياً على الحاسوب بلا استئذانك، وممكن يبعت حاله لكل عناوينك. انتبه للمرسلين المجهولين وفعّل Anti Virus.

4 واجهة Outlook 2016

Outlook من Microsoft لإرسال واستقبال الرسائل، وكمان لإدارة المواعيد والمهام والأعمال والاجتماعات. التشغيل: Start ← اكتب outlook 2016 ← انقر الأيقونة.

المكوّنشو فيه
شريط العنواناسم البرنامج والمجلد + Close/Minimize/Maximize + Ribbon Display Options: Auto-hide Ribbon · Show Tabs (العلامات بس) · Show Tabs and Commands (الاتنين سوا)
شريط الوصول السريعافتراضياً: Send/Receive All Folders و Undo
File و Ribbonعلامات تبويب (Home, Send/Receive, Folder, View) ← مجموعات منطقية (متل Respond) ← أوامر
جزء التنقل بين المجلداتالمجلدات: Inbox · Outbox · Sent Items · Deleted Items · Junk E-mail (View ← Layout ← Folder Pane)
جزء الرسائلقائمة الرسائل: Subject · From · Received · Size · Attachment (Add Columns لإضافة غيرها)
جزء القراءةمحتوى الرسالة اللي نقرت عليها (Right أو Bottom من View ← Layout ← Reading Pane)
جزء التنقل · شريط الحالةطريقة عرض جزء المجلدات · معلومات عن عناصر المجلد والعمليات الجارية

5 إنشاء الرسائل وإرسالها

Home ← New ← New Email.

الحقلمعناه
Fromعنوان المرسل
Toالمرسل إليهم الأساسيين
Cc Carbon Copyنسخة طبق الأصل لشخص مو طرف بس بيهمه الأمر
Bcc Blind Carbon Copyنسخة مخفية: عناوينهم ما بتبين للباقيين (لإظهاره: Options ← Show fields ← Bcc)
Subjectعنوان الرسالة

أكتر من عنوان بالحقل؟ بينهم فاصلة منقوطة ;

📎 Attach Fileنسخة من ملف أو أكتر (Browse This PC إذا مو بالقائمة).
✉️ Attach Itemنسخة من إيميل سابق (Outlook Item).
✍️ Signatureتوقيع بيعرّف بالمرسل (Signatures and Stationery ← New).
❗ الأولويةMessage ← Tags: High = إشارة تعجب حمرا · Low = سهم أزرق لتحت.
💡 وين بتروح الرسالة؟

Send مع إنترنت ← بتنبعت وبتنحفظ نسخة بـSent Items. بلا إنترنت ← Outbox. سكّرتها بلا إرسال وقلت Yes ← Drafts.

⚠️ فخ امتحان

إشعار الاستلام Request a Delivery Receipt وإشعار القراءة Request a Read Receipt بتفعّلهم قبل الإرسال (Options ← Tracking)، مو بعده.

7 جهات ومجموعات الاتصال

جهة الاتصال Contact = عنوان بريد لشخص محدد. مجموعة الاتصال Contact Group = عناوين أشخاص بيشتركو بصفة (متل طلاب صف)، فبتبعتلهم كلهم سوا بلا ما تحددهم واحد واحد.

  1. 1

    جهة اتصال

    Home ← New ← New Items ← Contact ← عبّي الحقول ← Save & Close.

  2. 2

    مجموعة اتصال

    Home ← New ← New Items ← More Items ← Contact Group.

  3. 3

    إضافة أعضاء

    افتح المجموعة ← Members ← Add member ← From Outlook Contacts ← Save & Close.

  4. 4

    الاستخدام

    برسالة جديدة اضغط To ← دفتر العناوين Address Book ← اختار لـTo أو Cc أو Bcc.
