أساسيات نظام التشغيل ويندوز 10

شو الجديد بويندوز 10، سطح المكتب والفأرة، خيارات التشغيل، العمل مع الأيقونات والنوافذ، لوحة التحكم وإدارة الطباعة، وأهم الاختصارات.

🔑 كلمات مفتاحية

سطح المكتب Desktopشريط المهام السكون Sleepالسبات Hibernate أيقونة Iconاختصار Shortcut شريط العنوانلوحة التحكمTask Manager

🎯 بعد هالفصل لازم تقدر:

  • تعدد ميزات ويندوز 10 ومكوّنات بيئة العمل
  • تفرّق بين خيارات التشغيل (سكون، سبات، تأمين، تسجيل خروج...)
  • تحدد وتحرّك الأيقونات وتنشئ اختصارات
  • تتعامل مع النوافذ: أقسامها، حجمها، إغلاقها، ترتيبها
  • تستخدم لوحة التحكم وتدير الطباعة، وتحفظ أهم الاختصارات

1 شو الجديد بويندوز 10؟

نظام التشغيل هو الوسيط بين البرامج التطبيقية اللي بتستخدمها وبين عتاد الحاسوب. ويندوز 10 من مايكروسوفت جاب تحسينات كتير:

📱 نظام واحد لكل الأجهزةمكتبي، محمول، لوحي، وهاتف ذكي.
🪟 قائمة ابدأ Startبتجمع القائمة الكلاسيكية (Windows 7) مع تطبيقات التصميم الحديث (Windows 8).
🎙️ Cortanaمساعد رقمي صوتي: بتنفّذ المهام بنطق الأوامر.
🌐 Microsoft Edgeمتصفح قوي ومنافس، بيقدر يعرض النص بس لقراءة أسهل على الشاشات الصغيرة.
🗂️ عرض المهام Task Viewالمهام اللي نفّذتها خلال آخر 30 يوم، وبيسمح بإنشاء أكتر من سطح مكتب.

3 خيارات التشغيل (Start ← Power)

أسوأ غلطة: تقطع الكهربا فجأة عن الحاسوب، لأنه بيأثر على استقرار النظام. لهيك في خيارات طاقة آمنة:

الخيارشو بيعمل
إعادة التشغيل Restartبينهي الجلسة وبيعيد تشغيل الحاسوب
إيقاف التشغيل Shut downبينهي الجلسة وبيطفي الحاسوب
السبات Hibernateبيفصل التغذية مع الحفاظ عالجلسة، وبترجع الجلسة بـزر الطاقة
السكون Sleepبيحافظ عالجلسة لتوفير الطاقة، وبترجع بـأي زر من لوحة المفاتيح أو تحريك الفأرة
تسجيل الخروج Sign outبيطلعك من الجلسة بلا ما يطفي الحاسوب
التأمين Lockبيقفل الحاسوب مع الحفاظ عالجلسة
تغيير إعدادات الحسابصلاحيات كاملة Administrator أو محدودة Standard
⚠️ فخ امتحان

السبات ← زر الطاقة. السكون ← أي زر أو الفأرة. والاتنين بيحافظو عالجلسة.

4 العمل مع الأيقونات

الأيقونات الأساسية لسطح المكتب: This PC (مشغلات الأقراص) · ملفات المستخدم (المستندات، الصور، الموسيقى) · الشبكة · سلة المحذوفات · لوحة التحكم. بتظهرها أو بتخفيها من: زر يمين على سطح المكتب ← Personalize ← Themes ← Desktop Icon Settings.

تحديد أيقونات متباعدةتحديد أيقونات متجاورة
انقر الأولى، واضغط Ctrl باستمرار وانقر الباقيانقر الأولى، واضغط Shift باستمرار وانقر الأخيرة

تحريك الأيقونات: بالسحب والإفلات، بس لازم أول تلغي الترتيب التلقائي: زر يمين ← View ← Auto arrange icons.

فتح عنصر: نقر مزدوج · أو Enter بعد التحديد · أو زر يمين ← Open · أو Open من قائمة Home.

الاختصار Shortcut: زر يمين ← Send To ← Desktop (create shortcut). بتسمّيه بـRename وبتحذفه بـDelete.

💡 مهم

حذف الاختصار ما بيحذف العنصر الأصلي.

6 لوحة التحكم وإدارة الطباعة

لوحة التحكم بتغيّر إعدادات ويندوز: الوقت والتاريخ، الصوت، الخلفية، شاشة التوقف، دقة الشاشة، اللغة...

المهمةالمسار
معلومات النظامSystem and Security ← System
الوقت والتاريخClock and Region ← Set the time and date
الصوتHardware and Sound ← Adjust system volume
إزالة برنامجPrograms ← Programs and Features ← Uninstall
تثبيت طابعةHardware and Sound ← Add a device
طابعة افتراضيةDevices and Printers ← زر يمين ← Set as Default Printer

الطباعة: File ← Print أو Ctrl + P. ومهام الطباعة بتشوفها بنقر مزدوج على أيقونة الطابعة بمنطقة الإعلام:

⏸️ Pauseإيقاف مؤقت.
▶️ Resumeبيكمّل من النقطة اللي وقف عندها.
🔁 Restartبيعيد الطباعة من البداية.
⛔ Cancelإيقاف كامل ونهائي.
