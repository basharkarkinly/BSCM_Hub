1 الملفات والمجلدات ووحدات التخزين

البيانات بتنخزّن على شكل ملفات Files (نصوص، صور، صوت...). ولتنظيمها بنحطها جوّا مجلدات Folders، والمجلد ممكن يحتوي ملفات ومجلدات فرعية.

⚠️ فخ امتحان

«المجلدات بتنحفظ داخل الملفات» = غلط. الملفات هي اللي بتنحفظ داخل المجلدات.

💽 القرص الصلبأهم وحدة تخزين، فيه نظام التشغيل والبرامج.
💿 CD و DVDلتخزين البيانات وحذفها، والـDVD سعته أكبر وجودته عالية.
🔌 USB Flashصغيرة، سهلة الحمل، سريعة، وسعتها كبيرة.
🌐 أقراص الشبكةلتخزين الملفات ومشاركتها إذا الحاسوب متصل بالشبكة.

2 إنشاء المجلدات والملفات واللواحق

  1. 1

    زر يمين بمكان فارغ

    New ← Folder، فبتطلع أيقونة صفراء باسم New folder. اكتب الاسم واضغط Enter.

  2. 2

    من شريط القوائم

    جوّا المجلد الأساسي: Home ← المجموعة New ← New folder (مجلد فرعي).

  3. 3

    بالاختصار

    Ctrl + Shift + N بأي مكان.

الملف هو المكان اللي بتنخزّن فيه البيانات فعلياً، ونوعه بيتحدد عادة من اللاحقة:

اللاحقةنوع الملف
docx · xlsx · pptx · accdbWord · Excel · PowerPoint · Access 2016
txtمستند نصي بسيط (نصوص بس)
pdfAdobe Acrobat Reader
gif · bmp · jpeg · jpgصور
wma / wmvملف صوتي / ملف فيديو
exe · zip · tmpتنفيذي (تطبيق) · مضغوط · مؤقت (بيعمله ويندوز أو البرامج وبينحذف بعدين)

مثال: برنامج الدفتر WordPad (Start ← Windows Accessories ← WordPad) لمستندات نصية بتنسيقات بسيطة. الاسم الافتراضي للملف Document ونوعه RTF.

3 الحفظ، القراءة فقط، وإعادة التسمية

Ctrl + S بيحفظ أي نوع ملف. والحالة الافتراضية للملف قراءة وكتابة Read-Write (بتفتح وبتعدّل).

💡 حماية الملف من التعديل

زر يمين ← Properties ← فعّل Read-only ← OK. هيك بتقدر تطّلع عليه بس. وإذا عملت مجلد Read-only، كل الملفات جوّاته بتصير للقراءة فقط.

إعادة التسمية: حدد وكبس F2 · أو انقر على الاسم · أو زر يمين ← Rename · أو Home ← Organize ← Rename. وبعدين Enter.

5 الحذف والاستعادة وسلة المحذوفات

الملف المحذوف بيروح على سلة المحذوفات Recycle Bin وبيضل فيها لحد ما تفرّغها، فبتقدر تستعيده.

العمليةالطرق
الحذفزر يمين ← Delete · Home ← Delete · اسحبه عالسلة · مفتاح Delete
الحذف النهائيShift + Delete (بلا سلة المحذوفات)
الاستعادةزر يمين ← Restore · Recycle Bin Tools ← Restore the selected items · أو اسحبه للمكان المطلوب
إفراغ السلةزر يمين على السلة ← Empty Recycle Bin · أو من Recycle Bin Tools
💡 ما عم ينحذف؟

غالباً الملف مفتوح ببرنامج شغّال. سكّر البرنامج أو أعد تشغيل الحاسوب.

6 طرق العرض والترتيب

طرق العرض (زر يمين بمكان فارغ ← View): أيقونات كبيرة جداً / كبيرة / متوسطة / صغيرة · List · Details · Tiles · Content.

الترتيب (زر يمين ← Sort by): حسب الاسم، تاريخ التعديل، النوع، أو الحجم، تصاعدياً أو تنازلياً. ومع عرض Details بتقدر ترتّب بالنقر على عنوان العمود.

تصاعدي Ascending ⬆️تنازلي Descending ⬇️
المجلدات أولاً ثم الملفاتالملفات أولاً ثم المجلدات
بالاسم: أرقام ← إنكليزي ← عربيبالاسم: عربي ← إنكليزي ← أرقام

7 البحث وضغط الملفات

لما تدخل على مربع البحث بتطلع قائمة Search فيها:

المجموعةالأوامر
المكان LocationThis PC (كل الحاسوب) · Current Folder (الحالي بس) · All subfolders (الحالي + الفرعية)
نوع البحث RefineDate modified · Kind (صورة، مستند، فيديو) · Size
خيارات OptionsRecent Searches · Advanced options (البحث جوّا المحتوى) · Save Search · Open file location · Close search

ضغط الملفات بيقلّص حجمها، فبيوفّر مساحة وبيقلّل وقت الإرسال بالبريد. والمضغوط بيتعامل معه متل العادي.

  1. 1

    للضغط

    حدد العناصر ← زر يمين ← Send to ← Compressed (zipped) folder ← اكتب الاسم ← Enter.

  2. 2

    للاستخراج

    زر يمين على المجلد المضغوط ← Extract files ← حدد المسار ← OK.

  3. 3

    برامج خاصة

    متل WinRAR.
