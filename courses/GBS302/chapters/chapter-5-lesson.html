معالج النصوص Word: البداية والتحرير

واجهة Word 2016، إنشاء المستندات والقوالب، الحفظ وصيغ الملفات، إدخال النص وأنماط الكتابة، تحديد النصوص، النسخ والتراجع والبحث والاستبدال والحذف، وطرق العرض.

🔑 كلمات مفتاحية

مستند Documentقالب Template Save Asdocx / pdf / txt Undo / RedoFind & Replace DraftSplit

🎯 بعد هالفصل لازم تقدر:

  • تعرف مكوّنات واجهة Word 2016
  • تنشئ مستند فارغ أو من قالب، وتحفظه بالصيغة المناسبة
  • تحدد الكلمة والجملة والسطر والفقرة بالطريقة الصح
  • تستخدم النسخ والقص والتراجع والبحث والاستبدال ومفاتيح الحذف
  • تفرّق بين طرق عرض المستند

1 واجهة برنامج Word 2016

Word من حزمة Office من مايكروسوفت. بتشغّله من Start ← اكتب Word 2016 بمربع البحث.

2 إنشاء المستندات والقوالب

المستند ملف فيه مجموعة صفحات.

  1. 1

    مستند فارغ

    File ← New ← Blank Document، أو Ctrl + N.

  2. 2

    من قالب Template

    File ← New ← اختار قالب، أو ابحث بـSearch for online templates.

💡 القالب

نوع من المستندات الجاهزة لغرض معين بتنسيقات معرّفة مسبقاً للصفحة والخطوط والألوان. مثلاً بدل ما تكتب سيرتك الذاتية من الصفر، بتختار قالب Blue Grey Resume.

4 إدخال النص وأنماط الكتابة

النص بينكتب عند نقطة الإدراج، وبتحرّكها بالأسهم أو بالفأرة. Enter = فقرة جديدة أو سطر فارغ. Alt + Shift = تبديل اللغة.

الرموز الخاصة (© ® ™ &): Insert ← Symbols ← Symbol ← More symbols.

نمط الإدراج Insert (الافتراضي)نمط الكتابة الفوقية Overtype
بيضيف النص مكان المؤشر وبيزيح القديم بلا حذفبيكتب فوق النص القديم وبيحذفه

بتبدّل بينهم: زر يمين على شريط الحالة ← فعّل Overtype ← انقر زر Insert / Overtype بشريط الحالة.

5 تحديد النصوص

قبل أي تنسيق لازم تحدد. بالفأرة (سحب) أو بلوحة المفاتيح (Shift + الأسهم).

لتحديدالطريقة
كلمةنقر مزدوج عالكلمة
جملةCtrl + نقرة بأي مكان من الجملة
سطرحرّك المؤشر لهامش السطر لحتى يصير سهم أبيض وانقر
فقرة3 نقرات عالفقرة، أو نقر مزدوج عالهامش الأيمن
المستند كلهCtrl + A أو Home ← Editing ← Select ← Select All
⚠️ فخ امتحان

«لتحديد كلمة ننقر 3 مرات» = غلط. الكلمة نقر مزدوج، والـ3 نقرات للفقرة.

6 النسخ والتراجع والبحث والاستبدال والحذف

📋 نسخ / قص / لصقHome ← Clipboard: Ctrl + C (نسخة تانية) · Ctrl + X (نقل النص نفسه) · Ctrl + V.
↩️ تراجع / ↪️ إعادةمن شريط الوصول السريع: Ctrl + Z / Ctrl + Y.
🔍 بحث FindHome ← Editing ← Find أو Ctrl + F (جزء Navigation).
🔁 استبدال ReplaceCtrl + H: Find What / Replace with ← Replace أو Replace All (كل النصوص).
المفتاحبيحذف (بلا تحديد)
Backspaceالحرف قبل المؤشر
Deleteالحرف بعد المؤشر
Ctrl + Backspaceمن المؤشر لـبداية الكلمة
Ctrl + Deleteمن المؤشر لـنهاية الكلمة
💡 حسب المقرر

فيك تحذف حروف أو كلمات بلا ما تحددها بهالمفاتيح. ولو حطيت المؤشر بآخر الفقرة الأولى وكبست Delete، بتندمج الفقرة التانية معها.

7 طرق عرض المستند والنوافذ

طريقة العرض (View ← Views)شو بتعرض

Read Mode وضع القراءةأفضل طريقة للقراءة

Draft مسودةبلا التنسيقات المتقدمة: حدود الصفحة، الترويسات، التذييلات، الصور

التكبير: منزلق Zoom بشريط الحالة أو View ← Zoom (و100% للرجوع). Split: بيقسم النافذة لتشوف جزأين وتعدّل (Remove Split للإلغاء). Switch Windows: للتنقل بين المستندات المفتوحة. وفيك تستعرض نفس المستند بأكتر من نافذة.
