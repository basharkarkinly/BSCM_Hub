1 تنسيق النصوص وأنماط الخط

التنسيق = العمليات اللي بتعملها على الكلمات أو الجمل أو الفقرات لتعطيها طابع شخصي. وكل أوامر الخط بمجموعة Font بعلامة Home: نوع الخط، الحجم (وزرّي Increase / Decrease Font Size)، اللون، تمييز النص Text Highlight (و No Color للإزالة).

💡 معاينة قبل الاعتماد

Word 2016 بيخلّيك تعاين الخط قبل ما تعتمده: بس تحط الماوس على نوع الخط، النص المحدد بيتغيّر مؤقتاً.

النمطالاختصار
غامق BoldCtrl + B أو Ctrl + 2
مائل ItalicCtrl + I أو Ctrl + 3
تسطير UnderlineCtrl + U أو Ctrl + 4
تسطير مزدوج Double Underlineما إله اختصار

كمان: Subscript منخفض (X₂) و Superscript مرتفع (X²) · Change Case لتغيير حالة الأحرف · Clear All Formatting لحذف كل التنسيقات.

3 القوائم والأنماط ونسخ التنسيق

القوائم بتربط الفقرات: مرقمة Numbering (مرتبة) أو نقطية Bullets (غير مرتبة). ولتغيير بداية الترقيم: Numbering ← Set Numbering Value ← Start New List أو Continue from Previous List.

النمط Style = مجموعة تنسيقات جاهزة بتحافظ على تناسق النص وبتعطي مظهر موحد احترافي (Home ← Styles).

🖌️ نسخ التنسيق Format Painter

بينقل التنسيق من نص لنص لتنسّق المستند بشكل موحد: Home ← Clipboard ← Format Painter ← حدد النص الجديد. نقر مزدوج عليه = تطبيق على أكتر من نص · Esc = إيقاف.

6 تخطيط الصفحة والرأس والتذييل

من Page Layout ← Page Setup:

📏 الهوامش Marginsالمنطقة الفارغة حوالين حدود الصفحة، والنص بينكتب بين الهوامش. Custom Margins للقيم.
🔄 الاتجاه OrientationPortrait: الطول أكبر من العرض · Landscape: العرض أكبر.
📄 القياس Sizeفيك تغيّر قياس الصفحة.
✂️ فاصل صفحة Page Breakبينهي الصفحة وبيبلّش جديدة: Breaks ← Page أو Ctrl + Enter.
🔢 ترقيم الأسطرلإرشاد القارئ بالمستندات الطويلة والمركبة والقانونية.

الرأس والتذييل: مناطق ضمن الهوامش العلوية والسفلية لكل صفحة (Insert ← Header & Footer). فيك تحط أرقام الصفحات، التاريخ والوقت، الشعار، العنوان، اسم الملف أو المؤلف (Quick Parts).

⚠️ انتبه

الرأس والتذييل بيتطبقو على كل الصفحات افتراضياً. لتستثني صفحة الغلاف فعّل Different First Page. وأرقام الصفحات: Top of Page · Bottom of Page · Page Margins.

7 التدقيق والطباعة

Review ← Proofing ← Spelling & Grammar: خط أحمر تحت الخطأ الإملائي، وخط أزرق تحت الخطأ النحوي. بتختار البديل ← Change، أو Ignore إذا الكلمة صح، أو Add لتضيفها للقاموس.

File ← Print: الإعدادات عاليسار والمعاينة عاليمين — عدد النسخ، الطابعة، الصفحات، الاتجاه، الهوامش. عاين قبل ما تطبع.
