العروض التقديمية PowerPoint

واجهة PowerPoint 2016، إنشاء العروض وحفظها، الشرائح وتخطيطاتها، طرق الاستعراض، السمات والملاحظات والرأس والتذييل، تقديم العرض، وتأثيرات الانتقال والحركة والطباعة.

🔑 كلمات مفتاحية

شريحة Slideالعناصر النائبة Normal · Outline · Slide Sorterالسمة Theme F5 / Shift + F5TransitionAnimation

  • تعرف مكوّنات واجهة PowerPoint والعناصر النائبة

  • تعرف وين بتلاقي السمات والملاحظات والرأس والتذييل
  • تقدّم العرض وتتنقل فيه، وتطبّق الانتقالات والحركات

1 واجهة PowerPoint 2016

PowerPoint من حزمة Office، لعرض المعلومات بشكل شرائح تفاعلية متتالية فيها نصوص، صور ثابتة أو متحركة، فيديو ووسائط متعددة. والواجهة فيها نفس عناصر Word (شريط العنوان و Ribbon Display Options، شريط الوصول السريع، File، Ribbon) وكمان:

🖼️ المصغرات Thumbnailsالشرائح مصغرة بأرقامها، ومنها بتنقل وبتنسخ وبترتّب.
📝 جزء الشريحة Slide Paneمكان إدراج النصوص والجداول والصور.
⬚ العناصر النائبة Placeholderمربعات بحدود منقطة بمكان مقترح للعنوان والنص والكائنات.
📊 شريط الحالةمعلومات، تكبير وتصغير، طرق العرض، وجزء الملاحظات (ما بتظهر أثناء العرض).

2 إنشاء العروض وحفظها وإغلاقها

العرض التقديمي Presentation = ملف فيه مجموعة شرائح Slides.

بدكالطريقة
عرض جديد فارغFile ← New ← Blank Presentation · Ctrl + N
عرض من قالبFile ← New ← اختار قالب (أو ابحث online)، وزر Back للتراجع عن الإنشاء
حفظ لأول مرةFile ← Save (مو من Home)
حفظ التعديلاتFile ← Save · Ctrl + S · زر Save بشريط الوصول السريع
Save Asنسخة باسم أو مكان جديد بلا حذف الأصل
إغلاق العرض بس / البرنامجFile ← Close أو Ctrl + W / زر Close أو Alt + F4
فتح عرض موجودFile ← Open · Ctrl + O

3 إدراج الشرائح وتخطيطها وتحديدها

شريحة جديدة: Home ← Slides ← New Slide · أو زر يمين بالمصغرات ← New Slide · أو Ctrl + M.

التخطيط Layout: Home ← Slides ← Layout. كل تخطيط فيه عناصر نائبة (رسومات، جداول، مخططات، صور، أشكال) واسم التخطيط بيدلّك شو فيه.

لتحديدبجزء المصغرات
شريحة وحدةانقر عليها
شرائح متجاورةالأولى + Shift + الأخيرة
شرائح غير متجاورةCtrl + نقر على كل وحدة

نسخ Ctrl + C · قص Ctrl + X · لصق Ctrl + V · حذف: Delete أو زر يمين ← Delete Slide.

4 طرق استعراض العرض التقديمي (View ← Views)

الطريقةشو بتعرض
عادي Normalالافتراضية: جزء المصغرات + جزء الشرائح + جزء الملاحظات
مخطط تفصيلي Outline Viewالعناوين والنص الرئيسي من كل شريحة بجزء المصغرات
فارز الشرائح Slide Sorterكل الشرائح كصور صغيرة
صفحة الملاحظات Notes Pageنسخة مصغرة من الشريحة الحالية + قسم الملاحظات
عرض القراءة Reading Viewعرض الشرائح بلا الأشرطة والأوامر

وكمان فيك تغيّر طريقة العرض من شريط الحالة، والتكبير من منزلق Zoom أو View ← Zoom.

5 السمات والخلفية والملاحظات والرأس والتذييل

🎨 السمة Theme

مجموعة موحدة من خيارات التصميم والتنسيق بتعطي العرض مظهر متناسق وجميل: Design ← Themes. بتتطبق على كل الشرائح افتراضياً، ولشريحة معينة: زر يمين عالسمة ← Apply to Selected Slides.

بدكعلامة التبويب
تغيّر لون الخلفيةDesign ← Customize ← Format Background ← Fill ← Apply to All
حجم الشريحة (عمودي / أفقي)Design ← Customize ← Slide Size
ملاحظات العارضView ← Presentation Views، أو سهم Notes بشريط الحالة
الرأس والتذييل (التاريخ، رقم الشريحة، نص)Insert ← Text ← Header and Footer ← Apply أو Apply to All
⚠️ فخ امتحان

السمة ← Design (مو Insert). الملاحظات والتكبير ← View (مو Home). الرأس والتذييل ← Insert.
