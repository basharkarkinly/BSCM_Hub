1 واجهة Excel 2016

Excel من حزمة Office للأرقام والعمليات الحسابية والإحصائية والمالية والمخططات. الواجهة فيها نفس عناصر Word وPowerPoint، وكمان:

🏷️ مربع الاسم Name Boxاسم الخلية المحددة (حرف العمود ورقم السطر).
ƒx زر إدراج دالة Insert Functionلإدراج التوابع الرياضية.
📝 شريط الصيغة Formula Barبيظهر بيانات الخلية المحددة.
📊 شريط الحالةمعلومات، تكبير وتصغير، وطرق عرض ورقة العمل.

2 المصنفات

بدكالطريقة

من قالبFile ← New ← قالب جاهز متل Invoice للفواتير
حفظ / حفظ باسمSave أو Ctrl + S / Save As بلا حذف الأصل
إغلاق المصنف / البرنامجCtrl + W / Alt + F4
فتحFile ← Open · Ctrl + O

3 أوراق العمل

كل مصنف فيه ورقة عمل افتراضية وحدة = جدول إلكتروني مستقل. كل ورقة إلها علامة بـشريط أوراق العمل.

العمليةالطريقة
إضافة ورقةHome ← Cells ← Insert ← Insert Sheet · أو زر New Sheet بشريط الأوراق (اسمها Sheet2، Sheet3...)
إعادة التسميةنقر مزدوج على اسمها · أو زر يمين ← Rename، ثم Enter
تحديد متباعدة / متجاورةCtrl + نقر / الأولى + Shift + الأخيرة
التنقلانقر عالاسم لتصير نشطة · أسهم الشريط · Ctrl + سهم يمين لآخر ورقة · Ctrl + سهم يسار لأول ورقة
الحذفHome ← Cells ← Delete ← Delete Sheet · أو زر يمين ← Delete
نسخ / نقلHome ← Cells ← Format ← Move or Copy Sheet (فعّل Create a copy للنسخ، و To Book لمصنف تاني) · أو اسحب: مع Ctrl = نسخ، بلا Ctrl = نقل
⚠️ مهم

ما فيك تحذف كل أوراق العمل — لازم تضل ورقة وحدة عالأقل.

4 الأعمدة والصفوف والتجميد

التحديد: انقر على حرف العمود أو رقم الصف · اسحب لنطاق متجاور · Ctrl لأعمدة أو صفوف غير متجاورة أو مزيج منهم.

العمليةكيف
إدراجHome ← Cells ← Insert ← Insert Sheet Columns / Rows — بينضاف قبل المحدد. ولتضيف 4، حدد 4.
حذفHome ← Cells ← Delete ← Delete Sheet Columns / Rows · أو زر يمين ← Delete
العرض / الارتفاعFormat ← Column Width / Row Height · AutoFit للاحتواء التلقائي · أو اسحب المحددات بين الرؤوس

التجميد (View ← Window ← Freeze Panes): بيخلّي صفوف أو أعمدة ظاهرة وقت التمرير.

  1. 1

    الصف الأول / العمود الأول

    Freeze Top Row / Freeze First Column.

  2. 2

    أكتر من صف أو عمود

    حدد اللي بعدهم مباشرة (لأول 3 سطور حدد الرابع) ← Freeze Panes.

  3. 3

    صفوف وأعمدة معاً

    حدد الخلية الناتجة عن التقاطع ← Freeze Panes.

  4. 4

    الإلغاء

    Unfreeze Panes.

5 الخلايا والنطاقات والتنقل

الأعمدة حدها الأقصى 16,384 (بأحرف A, B, C...) والصفوف 1,048,576 (بأرقام). تقاطعهم = خلية، متل F3 = العمود F مع السطر 3. وفيك تدخل أرقام ونصوص وتواريخ.

التحديد: نقرة لخلية · Ctrl لخلايا غير متجاورة · سحب للمتجاورة. والخلايا المتتابعة اسمها نطاق Range: A1:D1 أفقي و A1:A4 عمودي.

المفتاحبيروح على
Enter / Shift + Enterالتالية / السابقة بنفس العمود
Tab / Shift + Tabالتالية / السابقة بنفس السطر
Homeأول خلية بالصف
Ctrl + Homeالخلية A1 (أول خلية بالورقة)
Ctrl + Endآخر خلية تم تحريرها
نقرة وحدة ثم كتابةنقرتين مزدوجتين
بتمسح القديم وبتكتب جديدبتعدّل مع الحفاظ على المحتوى القديم

نسخ Ctrl + C · قص Ctrl + X · لصق Ctrl + V · مسح المحتوى: Delete أو Clear ← Clear Contents.

6 البحث والاستبدال والفرز

Home ← Editing ← Find & Select: Find (Ctrl + F) أو Replace (Ctrl + H) — Find Next · Find All · Replace · Replace All.

الفرز: Home ← Editing ← Sort & Filter ← Sort Largest to Smallest أو Smallest to Largest. ولعمود تاني: Custom Sort ← Add Level ← Then By ← Order ← OK.
