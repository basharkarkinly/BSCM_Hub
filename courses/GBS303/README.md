# GBS303 — مهارات الدخول إلى سوق العمل

منصة دراسية تفاعلية (Support Channel). مبنية على بنية BAC504 ومدموجة بالهب (تسجيل دخول، تعليقات، قائمة جانبية).

## الهيكل
- `index.html` — الصفحة الرئيسية (خارطة 6 فصول + دائرة التقدم)
- `chapters/chapter-N-lesson|practice|exam.html` — درس / تدريب حر / امتحان الفصل (N = 1..6)
- `pages/final-exam.html` — الفحص النهائي: 50 سؤال × علامتين = 100، تايمر الوقت المستهلك فقط
- `assets/data/chN-questions.js` — بنك أسئلة كل فصل؛ `final-questions.js` يدمجهم
- `assets/data/course-manifest.js` — عناوين الفصول (مصدر واحد للرئيسية والقائمة)
- `assets/app.js` — المحرك المشترك (مع التعديلات الموضعية أدناه)

## تعديلات المحرك على BAC504 (موضعية)
- مفاتيح localStorage: `gbs303_progress_v1`, `gbs303_final_result_v1`, `gbs303_seen_v1`
- **تدوير الأسئلة:** امتحان الفصل والفحص النهائي بيسحبوا فقط أسئلة ما شافها الطالب (تُسجَّل عند الإجابة). لما يخلص البنك بتبدأ دورة جديدة مع ملاحظة. زر «أعد الفحص بأسئلة جديدة».
- الفحص النهائي: `count:50, marksPerQuestion:2, timer:true` (عدّاد وقت مستهلك بدون إنهاء تلقائي)
- خيارات «جميع الأجوبة…» بتضل آخر القائمة عند خلط الخيارات
- رابط «رجوع لخارطة المقرر» بنتيجة الفحص النهائي صار يستخدم `SITE_PREFIX`

## البنك
226 سؤال (صح/خطأ + اختيار من متعدد). `origin:"bank"` = أصله من أسئلة الدورات السابقة والإجابة محقّقة من نص المقرر، `origin:"gen"` = مولّد من المحتوى. كل سؤال له رابط «راجع الموضوع» لقسم الدرس.
بنك الفحص النهائي يكفي لـ 4 محاولات مختلفة كلياً (200 سؤال)، والخامسة بتبدأ دورة جديدة.

## الدمج بالهب
- `course_id` = `GBS303`، `chapter_id` = رقم الفصل (1..6)
- تبويب `courses` بالشيت: `course_id` و`code` = `GBS303`، وعمود `url` = رابط المقرر (بعد ما يشتغل)، و`status` = `active`
