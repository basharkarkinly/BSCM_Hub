Access — الجداول، الاستعلامات، النماذج والتقارير

الجداول والعلاقات والتكامل المرجعي، الاستعلامات وSQL، أنواع الوصل (JOIN)، والنماذج والتقارير.

1 أساسيات Access

  • امتداد ملفات Access: .accdb
  • إن لم يُحدَّد مفتاح رئيسي، ينشئ Access تلقائياً حقلاً باسم "المعرّف" بنوع "ترقيم تلقائي".
  • النص المختصر (Short Text): حتى 255 حرفاً كحد أقصى.
  • ملف Access الواحد يمكن أن يحتوي على أكثر من جدول.

2 العلاقات والتكامل المرجعي

أساس علاقة الجدول هو تناظر القيم بين حقول المفاتيح (الرئيسي في جدول والأجنبي في آخر).

📌 ملاحظة

التكامل المرجعي (Referential Integrity): يمنع السجلات المعزولة ويحافظ على تزامن المراجع. بعد فرضه، يرفض Access أي عملية تنتهك علاقة الجدول (مثل حذف سجل رئيسي مرتبط بسجلات فرعية، دون تفعيل التتالي).

الخيارالأثر عند تفعيله
تتالي تحديث الحقول المرتبطةتحديث المفتاح الرئيسي يحدّث تلقائياً كل الحقول المرتبطة به في الجداول الأخرى
تتالي حذف السجلات المرتبطةحذف سجل من جانب المفتاح الرئيسي يحذف تلقائياً كل السجلات المرتبطة به
📌 من أسئلة الدورات السابقة

لا يُفرض التكامل المرجعي مباشرة مع الاستعلامات؛ بل يُفرض بين الجداول عند إنشاء العلاقة.

3 الاستعلامات (Queries)

طريقتان لإنشائها: عرض التصميم (Design View) أو SQL.

النوعالوظيفة
استعلامات التحديد (Select)الأكثر شيوعاً — استعادة بيانات من جدول أو إجراء حسابات، لا تُعدّل مصدر البيانات فعلياً وتعرض النتائج دوماً محدّثة.
استعلامات إجرائيةالحذف، الإضافة، التحديث — تُجري تغييرات فعلية على السجلات.
استعلام المعلمات (Parameter)يعرض مربع حوار يطلب من المستخدم معلومات تُعامل كمعايير بحث، دون تعديل نص الاستعلام.
استعلامات التوحيد (Union)تضم حقولاً من جدولين/استعلامين أو أكثر في نتيجة واحدة.

بنية استعلام SQL أساسي

SELECT حقل1, حقل2 FROM الجدول WHERE شرط ORDER BY حقل;

  • DISTINCT — لحذف النتائج المكررة بعد SELECT.
  • ORDER BY — لترتيب السجلات وفق معيار محدد.
  • GROUP BY — لضمّ السجلات ذات القيم المتماثلة، غالباً مع دالة حسابية.
  • HAVING — لتحديد شرط على السجلات المجمّعة بواسطة GROUP BY (بعد التجميع).
  • BETWEEN...AND — قيمة ضمن نطاق محدد.
  • LIKE — مقارنة سلسلة محارف بعامل بحث (يُستخدم مع #, *, ?).
  • IN — القيمة تساوي إحدى القيم في قائمة محددة.
📌 من أسئلة الدورات السابقة

الدوال التجميعية Max/Min: تُستخدم مع الأرقام والتواريخ والنصوص (ترتيباً أبجدياً).

SQL = Structured Query Language (لغة الاستعلام البنيوية). ومن الأنظمة التي تعتمدها: SQL Server وOracle وMySQL.

أمر الحذف في SQL: DELETE.

مثال تحديث: UPDATE Products SET price = price * 50% تخفّض السعر إلى 50% من قيمته (الضرب بـ50% وليس الطرح) · وحذف جدول كامل: DROP TABLE · وإنشاؤه: CREATE TABLE.

4 طرق الوصل بين الجداول (JOIN)

النوعالنتيجة
INNER JOINالسجلات المتطابقة فقط بين الجدولين (قيمة مشتركة بالحقل المشترك)
LEFT JOINكل سجلات الجدول الأول + المطابقة فقط من الجدول الثاني
RIGHT JOINكل سجلات الجدول الثاني + المطابقة فقط من الجدول الأول
📌 ملاحظة

عند عدم وجود حقل مشترك بين جدولين نريد ربطهما، نضيف جدولاً وسيطاً يعمل كمعبر بينهما (غالباً في علاقات M:N).

5 النماذج (Forms) والتقارير (Reports)

  • نموذج مرتبط: متصل مباشرة بمصدر بيانات (جدول/استعلام).
  • نموذج غير مرتبط: لا يرتبط بمصدر بيانات، يحوي أزرار/عناصر تحكم فقط.
  • نموذج منقسم: يمنح طريقتي عرض (نموذج + ورقة بيانات) لمصدر البيانات نفسه في آن واحد.
  • نموذج فرعي: نموذج مضمّن داخل نموذج رئيسي — مفيد لعرض علاقة واحد لمتعدد.
طريقة العرضالاستخدام
عرض التخطيط (Layout)الأكثر بديهية للتعديل — النموذج يعمل فعلياً فترى البيانات الحقيقية أثناء التعديل
عرض التصميم (Design)أكثر تفصيلاً لبنية النموذج (رأس/تفصيل/تذييل) — لا يعمل النموذج فعلياً أثناء التعديل

عناصر التحكم: منضم (مصدره حقل من جدول/استعلام) — غير منضم (لا مصدر بيانات، كالتسميات) — محسوب (مصدره تعبير/معادلة).

مقاطع التقرير

المقطعيظهر

رأس الصفحةفي أعلى كل صفحة
رأس المجموعةفي بداية كل مجموعة سجلات جديدة

Access والعلاقات

عند إنشاء جدول دون مفتاح رئيسي، يمكن لـAccess إنشاء حقل «المعرّف» بترقيم تلقائي وفهرس للمفتاح. يضمن التكامل المرجعي منع السجلات المعزولة وتزامن المراجع؛ وتحديث المفتاح الرئيسي أو حذفه يمكن أن يتالى إلى السجلات المرتبطة عند تفعيل الخيار المناسب.

الاستعلامات وSQL

النوع/البندالغرض
SELECT / FROMاستعادة حقول من جدول أو أكثر؛ النتائج لا تُخزّن ثابتة وتُحدّث عند التشغيل.
WHEREتصفية السجلات بمعيار، مع AND وOR.
DISTINCT / ORDER BYإزالة التكرار / ترتيب النتائج.
GROUP BY / HAVINGتجميع القيم ثم وضع شرط على المجموعات.
BETWEEN, LIKE, INنطاق، مطابقة نمط، أو قائمة قيم.
Action Queriesحذف Delete، إضافة Append، تحديث Update.

الدوال التجميعية: Sum وAvg وMin وMax. الاستعلام الفرعي SELECT داخل استعلام آخر ويُنفذ أولاً؛ واستعلام المعلمات يطلب من المستخدم قيمة عند التشغيل.

الجداول الافتراضية والربط

الجدول الافتراضي يعرض بيانات مشتقة دون تعديل الأصل، ويعزز الأمان ويتيح تسميات أو بنية عرض مناسبة. استخدم INNER JOIN للمطابق فقط، وLEFT JOIN لكل سجلات الجدول الأول مع المطابق، وRIGHT JOIN لكل سجلات الثاني مع المطابق. UNION يدمج نتائج متوافقة من مصدرين.

النماذج والتقارير

  • النموذج المرتبط: متصل بجدول أو استعلام؛ وغير المرتبط للأوامر والتسميات وعناصر التحكم.
  • النموذج المنقسم: يعرض النموذج وورقة البيانات معاً؛ والنموذج الفرعي مناسب لعلاقة واحد لمتعدد.
  • Layout View: تعدّل مع ظهور بيانات حقيقية. Design View: تحكم أكبر في الرأس والتفصيل والتذييل، لكن النموذج لا يعمل فعلياً أثناء التعديل.
  • التقارير: تنسيق وتلخيص وعرض/توزيع/أرشفة البيانات؛ مصدر سجلاتها جدول أو استعلام.
