1 Excel: الدوال على نطاق فيه نص ومنطقية

الدالةشو بتحسب؟
SUM / COUNT / MIN / MAX / AVERAGEالأرقام فقط؛ تتجاهل النص والمنطقية والفارغ
COUNTAكل الخلايا غير الفارغة
MINA / MAXA / AVERAGEAغير الفارغ: النص = 0 · TRUE = 1 · FALSE = 0
SUBTOTAL(9,…) / (109,…)9 يُدرج الصفوف المخفية · 109 يتجاهلها
INT / TODAYالقيمة الصحيحة دون كسور · تاريخ اليوم
PV / FV / NPVقيمة حالية · مستقبلية · صافي القيمة الحالية (مربح إذا NPV أكبر من 0)

البندالخلاصة

$A$1مطلق: ثابت
$A1 / A$1مختلط: ثبات جزئي
* ? #* حروف بعدد غير محدد · ? حرف واحد · # العرض لا يتّسع
الترتيبالأقواس ← الرفع لقوة ← الضرب والقسمة ← الجمع والطرح ← الضمّ & ← المقارنة
القيم المنطقيةTRUE = 1 · FALSE = 0 داخل العمليات الحسابية
