# كود السيرفر (Google Apps Script)

هالمجلد نسخة من كود السيرفر للمتابعة والتاريخ. **السيرفر الحقيقي بيشتغل من مشروع Apps Script**، مو من هون.

## الملفات
| الملف هون | اسمه بمشروع Apps Script |
|---|---|
| `Code.gs` | `Code.gs` — الدخول، الجلسات، الحساب، التنظيف الليلي |
| `Comments.gs` | `Comments.gs` — التعليقات، الإشعارات، شريط الأخبار، الكاش |
| `Placement.gs` | `Placement.gs` — نتائج اختبار المستوى والاستبيان |

## كيف تنشر تعديل
1. افتح مشروع Apps Script، وبكل ملف: امسح كل المحتوى والصق الملف كامل من هون.
2. احفظ (Ctrl+S).
3. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy.**
   (هيك الرابط `/exec` بيضل نفسه وما بتحتاج تغيّر `assets/config.js`.)

## بعد نسخة v6 (مرة وحدة بس)
من المحرر اختار `setupV3` واضغط **Run**. بتضيف الأعمدة الجديدة، بتعبّي أماكن تعليقات الطلاب، وبتركّب مؤقّتين:
- `dailyCleanup` كل ليلة: بتمسح الجلسات المنتهية ورموز التحقق القديمة، وبتأرشف النقاشات الأقدم من 180 يوم.
- `onSheetEdit`: لما تعدّل تبويب `comments` بإيدك (تخفي تعليق مثلاً) بيتفرّغ كاش التعليقات فوراً.

إذا عدّلت التعليقات بطريقة تانية وما ظهر التعديل، شغّل `clearCommentsCache`.

> تنبيه: هالـ repo عام، فالكود هون بيشوفه أي حدا. ما في أسرار فيه (SHEET_ID و PEPPER محفوظين بـ Script Properties)، فلا تحط أي مفتاح أو إيميل حقيقي جوّا الكود.
