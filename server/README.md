# كود السيرفر (Google Apps Script)

هالمجلد نسخة من كود السيرفر للمتابعة والتاريخ. **السيرفر الحقيقي بيشتغل من مشروع Apps Script**، مو من هون.

## الملفات
| الملف هون | اسمه بمشروع Apps Script |
|---|---|
| `Code.gs` | `Code.gs` — الدخول، الجلسات، الحساب، التنظيف الليلي |
| `Comments.gs` | `Comments.gs` — التعليقات، الإشعارات، شريط الأخبار، الكاش |
| `Placement.gs` | `Placement.gs` — نتائج اختبار المستوى والاستبيان |
| `Stars.gs` | `Stars.gs` — النجوم ⭐، نجوم الامتحانات، الكلمات الممنوعة |

## كيف تنشر تعديل
1. افتح مشروع Apps Script، وبكل ملف: امسح كل المحتوى والصق الملف كامل من هون.
2. احفظ (Ctrl+S).
3. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy.**
   (هيك الرابط `/exec` بيضل نفسه وما بتحتاج تغيّر `assets/config.js`.)

## بعد نسخة v6 (مرة وحدة بس)
من المحرر اختار `setupV3` واضغط **Run**. بتضيف الأعمدة الجديدة، بتعبّي أماكن تعليقات الطلاب، وبتركّب مؤقّتين:
- `dailyCleanup` كل ليلة: بتمسح الجلسات المنتهية ورموز التحقق القديمة، وبتأرشف النقاشات الأقدم من 180 يوم.
- `onSheetEdit`: لما تعدّل تبويب `comments` بإيدك (تخفي تعليق مثلاً) بيتفرّغ كاش التعليقات فوراً.

إذا عدّلت التعليقات بطريقة تانية وما ظهر التعديل، شغّل `clearCommentsCache`.

## بعد نسخة v7 — النجوم والأسئلة (مرة وحدة بس)
1. أنشئ ملف جديد بالمشروع اسمه `Stars.gs` والصق فيه الملف من هون.
2. من المحرر اختار `setupV4` واضغط **Run**. بتنشئ:
   - `star_rules`: أرقام النجوم والسقف اليومي والتفعيل (عدّل منها بأي وقت بدون كود).
   - `stars_ledger`: كل حركة نجوم (المرجع). إذا عدّلتو بإيدك شغّل `adminRebuildStars`.
   - `votes`: أصوات 👍.
   - `banned_words`: كلمة ممنوعة بكل سطر. أي سؤال أو جواب أو اسم فيه وحدة منها ما بينتشر.
3. **مهم لنجوم الامتحانات:** المقرر لازم يكون `active` بتبويب `courses`، والـ `course_id` تبعو نفس اسم المجلد (مثلاً `BMN401`) أو رابطو فيه `/courses/BMN401/`.

4. `setupV4` كمان بتعطي كل طالب موجود **نجوم الترحيب** ورمز دعوة (مرة وحدة، وآمنة إذا انعادت).

**الترحيب والدعوات:** كل طالب جديد بياخد نجوم `welcome`. ورابط الدعوة `index.html?ref=رمز` بيعطي اللي دعا نجوم `referral` **لما الصديق يبلّش يدرس** (أول امتحان ينجح فيه أو أول سؤال/جواب)، مو لحظة التسجيل. ونفس الإيميل (حتى مع `+` أو نقاط بجيميل، أو بعد حذف الحساب وإعادة التسجيل) ما بياخد ترحيب مرتين وما بيجيب نجوم دعوة مرتين.

لإخفاء جواب مخالف: غيّر `status` تبعو بتبويب `comments` لـ `hidden` — نجومو بتنسحب لحالها.

> تنبيه: هالـ repo عام، فالكود هون بيشوفه أي حدا. ما في أسرار فيه (SHEET_ID و PEPPER محفوظين بـ Script Properties)، فلا تحط أي مفتاح أو إيميل حقيقي جوّا الكود.

## نسخة v8 — ساحة الأسئلة
بس الصق `Code.gs` و `Comments.gs` الجداد واعمل Deploy ← New version. ما في setup جديد.
- الأسئلة العامة بتنحفظ بنفس تبويب `comments` بـ `course_id = GENERAL` و `chapter_id = general`.
- سؤال عن مقرر كامل (مو فصل): `course_id = BMN401` و `chapter_id = general`.
